# Retained linear-application examples

These source examples describe mean, compliance rate, public-reference subtraction
and variance sufficient statistics. They are retained for inspection.

The inherited example package is incomplete: its shared `lib/scenario.mjs` module
is absent. Its `demo:*` and `test` scripts are therefore not runnable in this
snapshot. Do not use them as a reproduction entry point. The supported linear
workflow is `../../run-linear.sh`, documented in `../../REPRODUCE.md`.

The complete linear contract regression suite remains in `BN254-Signatures/test/`.
