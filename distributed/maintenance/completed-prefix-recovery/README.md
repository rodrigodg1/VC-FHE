# Completed-prefix continuation

This procedure is restricted to its validated ten-completed/seventeen-pending case frontier. `frontier.py`, `prefix_validation.py`, `reconcile.mjs` and `selection.py` enforce that boundary. Retain the predecessor, counters, keyset and pending-request evidence. This is not general recovery for arbitrary prefixes. Completion requires separate validation of each segment and composed exact coverage. See `../../OPERATIONS.md` before using any mutating command.
