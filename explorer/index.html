Linear path — fixed aggregation with output binding

Each data owner signs its own encrypted record. The contract admits each record once under that owner's key, then accepts the result only if its commitment equals the authorized accumulator. The consumer recomputes the digest and the commitment off chain before decrypting.

Non-linear path — optimistic authenticated trace

A task is accepted unless an auditor opens a bonded challenge. A challenged task forces complete trace disclosure, then logarithmic bisection down to one leaf, which an FHEVM verifier re-executes on chain. Vote counts never decide a contested computation.
